# Data

## Raw Data

The raw datasets are from the freMTPL2 motor third-party liability insurance dataset from CASdatasets.

- `freMTPL2freq.csv`: Policy-level frequency and risk characteristics
- `freMTPL2sev.csv`: Individual claim severity records

The raw datasets are not included in the GitHub repository due to file size. They can be obtained from the original dataset source.


## Processed Data

The `processed/` folder contains cleaned and aggregated datasets generated during the analysis and used for the Tableau dashboards.

- `portfolio_kpis.csv`
- `region_kpis.csv`
- `segment_kpis.csv`
- `policy_level.csv.gz` — compressed version of the full policy-level dataset
- `pareto.csv`
