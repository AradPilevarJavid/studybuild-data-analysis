# Data

This folder contains the raw and processed datasets used in the
**Insurance Claims & Portfolio Risk Analytics** project.

## 1. Raw Data

The original dataset is the public **French Motor Third-Party
Liability (freMTPL2)** dataset from CASdatasets.

It is provided as two related tables:

### `raw/freMTPL2freq.csv`

Policy-level data containing:

- Policy ID (`IDpol`)
- Number of claims (`ClaimNb`)
- Exposure period (`Exposure`)
- Driver and vehicle characteristics
- Fuel type
- Bonus-Malus
- Area and Region information

### `raw/freMTPL2sev.csv`

Claim-level data containing:

- Policy ID (`IDpol`)
- Claim amount (`ClaimAmount`)

The two tables are linked through `IDpol`.

## 3. Data Preparation

The Python workflow performs the following main steps:

1. Load the frequency and severity tables.
2. Inspect structure, data types, missing values, duplicates, and
   basic validity.
3. Aggregate claim-level records by `IDpol`.
4. Merge the aggregated claim information with the policy-level
   frequency data using a left join.
5. Validate the merge and claim counts.
6. Create driver and vehicle segments.
7. Calculate portfolio and segment-level KPIs.
8. Perform regional, frequency/severity, Pareto, and outlier analyses.
9. Export the processed CSV files for Tableau.

## 4. Important Data Notes

A policy may have multiple claims. Therefore, repeated `IDpol`
values in the severity table are expected and are not automatically
treated as duplicate policies.

Policies without observed claims are retained in the final
policy-level dataset.

For these policies:

- `TotalClaimCost = 0`
- `ClaimRecords = 0`

Average claim severity is only meaningful for observed claims and is
not interpreted as zero for policies without claims.

Large claim amounts are retained in the dataset. Potential outliers
are identified for review rather than automatically removed.

Loss Ratio is not calculated because written premium is not available
in the selected freMTPL2 dataset.

## 5. Reproducibility

The processed files in the `processed/` folder are generated by:

`notebooks/insurance_analysis.ipynb`

To reproduce the results, place the raw CSV files in the `raw/`
folder and run the notebook from beginning to end.
